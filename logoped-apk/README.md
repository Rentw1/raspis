# Логопед-конструктор (Android)

Приложение для учителя-логопеда группы компенсирующей направленности (ТНР/ОНР, ФФНР):
за минуту собирает занятие по лексической теме — конспект, технологическую карту,
цели и задачи, рабочий лист с картинками и задание родителям — и сохраняет всё в Word (DOCX)
по ГОСТ или отправляет на печать/PDF. Работает без интернета; интернет нужен только
для замены картинок.

МАДОУ «Центр развития ребенка – детский сад № 1 «Шатлык»», г. Набережные Челны
(название учреждения, ФИО и должность меняются в настройках).

## Почему задания теперь совпадают с темой

В прежней версии тема подставлялась только в текст, а задания и картинки выбирались
отдельно, поэтому к теме «Зимующие птицы» попадали ёлки и зимние забавы. Теперь всё
строится из одного словаря:

- у каждой из 40 лексических тем есть свой набор слов (462 слова с падежными формами,
  множественным числом, уменьшительной формой, детёнышами, признаками и действиями);
- каждое задание рабочего листа собирается **только из слов выбранной темы**
  (для «Четвёртого лишнего» и «Разложи по группам» лишний предмет берётся из смежной темы
  и в ответе названа его тема);
- картинка рисуется из **того же слова**, которое названо в тексте задания, поэтому текст,
  картинка и тема всегда совпадают;
- речь логопеда и ответы детей в конспекте используют те же слова, что и рабочий лист;
- звуковые задания (место звука, «поймай звук», слоги, первый звук) подбирают слова темы
  с нужным звуком по фонетике, а не по буквам (оглушение, мягкость, йотированные гласные).

## Установка на телефон

1. Скачайте файл `dist/Logoped-Konstruktor-v1.0.0.apk` (или артефакт сборки GitHub Actions).
2. Откройте его на телефоне и разрешите установку из этого источника
   (Настройки → Безопасность → «Установка неизвестных приложений»).
3. Запустите «Логопед-конструктор». Требуется Android 6.0 и новее.

Готовые документы сохраняются в папку «Загрузки/Логопед» (Android 10+) или «Загрузки».

## Возможности

| Раздел | Что есть |
| --- | --- |
| Темы | 40 лексических тем на учебный год (сентябрь — май) с подсказкой по месяцу, можно дописать свою тему — программа подберёт ближайшую |
| Группа | 4–5, 5–6, 6–7 лет; фронтальное, подгрупповое, индивидуальное; длительность по СанПиН 1.2.3685-21 |
| Направления | комплексное, лексико-грамматическое, звукопроизношение (автоматизация/дифференциация), связная речь, подготовка к грамоте |
| Звуки | [С], [С'], [З], [З'], [Ц], [Ш], [Ж], [Ч'], [Щ'], [Л], [Л'], [Р], [Р'], [К], [Г], [Х], [Й'] |
| Рабочий лист | 27 видов заданий: назови, четвёртый лишний, группы, один — много, посчитай, найди и посчитай, назови ласково, детёныши, кто что ест, кто где живёт, кому что нужно, словообразование, чей?, предлоги, поймай звук, место звука, слоги, первый звук, загадки, мнемотаблица, синквейн, лабиринт, дорожки, тени, наложенные картинки, раскраска, разрезная картинка |
| Документы | титульный лист, цель и задачи (образовательные, коррекционно-развивающие, воспитательные), интеграция областей, виды деятельности, оборудование, конспект по этапам с речью логопеда и ответами детей, технологическая карта, рабочий лист, ключи к заданиям, задание родителям, нормативная база и литература |
| Технологии | артикуляционная, дыхательная и пальчиковая гимнастика, динамическая пауза, су-джок, кинезиология, мнемотехника, синквейн, ИКТ |
| Картинки | встроенные цветные и контурные (для раскрашивания) картинки; замена любой картинки из интернета (ARASAAC, Openverse, Викисклад) или из галереи телефона |
| Экспорт | DOCX: Times New Roman 14, интервал 1,5, поля 30/15/20/20 мм, нумерация страниц; печать и PDF через системный диалог; «Отправить» в мессенджер/почту |

Нормативная база, на которую опираются документы: Федеральный закон № 273-ФЗ, ФГОС ДО,
ФОП ДО, ФАОП ДО (для детей с ТНР), Порядок организации образовательной деятельности,
Примерное положение о логопедической помощи, СП 2.4.3648-20, СанПиН 1.2.3685-21,
профстандарт «Педагог-дефектолог».

## Сборка

Нужны JDK 11+, `aapt2`, `zipalign`, `apksigner` и `android.jar` (API 23+). Проще всего:

```bash
sudo apt install aapt apksigner zipalign android-sdk-platform-23 default-jdk-headless
./build.sh            # → dist/Logoped-Konstruktor-v<версия>.apk
```

Если установлен Android SDK, скрипт возьмёт инструменты из `$ANDROID_HOME/build-tools`.
R8/D8 скачивается автоматически. Переменные: `VERSION_CODE`, `VERSION_NAME`, `KEYSTORE`,
`KEYSTORE_PASS`, `KEYSTORE_ALIAS`, `ANDROID_JAR`.

Ключ подписи `keystore/logoped.jks` лежит в репозитории, чтобы новые версии ставились
поверх старых без удаления данных. Для публикации в магазинах используйте свой ключ.

Проверка словаря и тем: `node tools/prepare_assets.js --check`.
Пересборка набора картинок OpenMoji: `node tools/prepare_assets.js`.

## Устройство

```
app/AndroidManifest.xml          — Android 6.0+ (minSdk 23), targetSdk 34
app/java/…/MainActivity.java     — WebView, сохранение файлов, печать, загрузка картинок
app/java/…/DocProvider.java      — выдача готовых файлов другим приложениям
app/assets/www/                  — само приложение (HTML/CSS/JS, без сети)
  data/db.js, data/themes_*.js   — словарь и лексические темы
  data/methods.js                — возрасты, технологии, нормативная база, литература
  js/tasks.js                    — генераторы заданий рабочего листа
  js/lesson.js                   — цели, задачи, этапы конспекта и техкарта
  js/phonetics.js                — упрощённая фонетика для звуковых заданий
  js/docx.js, js/export.js       — сборка DOCX по ГОСТ и HTML для печати
  js/images.js, js/art*.js       — картинки: OpenMoji и собственные рисунки
  js/online.js                   — поиск картинок в интернете
```
